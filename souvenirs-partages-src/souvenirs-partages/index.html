Comment ça marche

Trois étapes simples pour récupérer tous les souvenirs

Le parcours est pensé pour être compris par les organisateurs comme par les invités, même le jour de l'événement.

✨

1. Créez votre album

Ajoutez le nom de votre événement, choisissez vos options et obtenez un espace privé en quelques secondes.

⏱ ~30 secondes
📱

2. Partagez le QR code

Imprimez-le sur vos tables, invitations ou affiches. Les invités accèdent directement à l'album.

📲 Aucune installation
📷

3. Récupérez les souvenirs

Les invités ajoutent leurs photos. Vous modérez, consultez et téléchargez l'album complet après l'événement.

📦 Export ZIP inclus

Sécurité & confidentialité

Conçu pour respecter les événements privés

Chaque album dispose d'un lien unique. L'organisateur contrôle les accès, les ajouts et la visibilité des contenus. Les invités peuvent demander le retrait d'une photo à tout moment.

Accès privé

Un lien unique ou un QR code permet de limiter la diffusion de l'album.

Modération

L'organisateur peut masquer ou supprimer une photo sans complexité.

Durée paramétrable

La conservation des fichiers peut être limitée selon le forfait choisi.

Respect RGPD

Le prototype prévoit consentement, retrait et suppression des contenus.
