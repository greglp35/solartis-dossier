# Prompt de démarrage pour Claude Code

Tu vas travailler sur le fichier ZIP joint, qui contient un prototype HTML/CSS/JS nommé `souvenirs-partages`.

## Mission

Analyse le projet fourni, puis améliore-le comme un développeur front-end senior.

Objectif : transformer ce prototype en une landing page + démo produit claire, responsive, premium et exploitable pour présenter une solution de collecte privée de photos/vidéos d’événements via QR code.

## Contexte produit

La solution s’appelle **SouvenirsPartagés**.

Positionnement :

> L’album privé que vos invités remplissent simplement en scannant un QR code.

Le produit permet à un organisateur de créer un album privé pour un mariage, anniversaire, baptême, séminaire ou événement familial. Les invités scannent un QR code, ajoutent leurs photos depuis leur navigateur mobile, puis l’organisateur récupère les souvenirs dans une galerie privée.

## Contraintes importantes

- Ne copie aucun texte, design, logo, code, capture, nom, marque ou élément propriétaire d’un service existant.
- Garde une identité originale et légalement distincte.
- Utilise uniquement HTML, CSS et JavaScript vanilla.
- Ne pas ajouter de framework.
- Le projet doit fonctionner en local.
- Le design doit être mobile-first.
- Utilise des placeholders CSS, SVG simples, emojis ou dégradés.
- Ne pas utiliser d’images protégées.
- Conserver une bonne accessibilité : labels, aria-labels, contrastes, navigation clavier.

## Ce que tu dois faire en premier

1. Lire `README.md`.
2. Lire `DOSSIER_REFERENCE.md`.
3. Examiner `index.html`, `style.css` et `script.js`.
4. Lancer mentalement ou localement le prototype.
5. Identifier les améliorations UX, design et code.
6. Proposer un plan d’amélioration court avant de modifier les fichiers.

## Ton de l’interface

Le ton doit être :
- clair ;
- chaleureux ;
- rassurant ;
- premium ;
- non technique ;
- orienté événement privé.

## Messages clés à conserver

- Sans application obligatoire.
- QR code prêt à imprimer.
- Album privé.
- Upload depuis navigateur mobile.
- Galerie consultable en direct.
- Export complet après l’événement.
- Respect de la confidentialité.
- Utilisable pour mariages, anniversaires, baptêmes, séminaires et fêtes de famille.

## Résultat attendu

À la fin, le projet doit être une base front-end solide pour vendre ou présenter un MVP no-code / SaaS de collecte de photos d’événements via QR code.
