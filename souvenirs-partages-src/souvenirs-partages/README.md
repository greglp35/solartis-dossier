# SouvenirsPartagés

Prototype HTML/CSS/JS d’une solution de collecte privée de photos et vidéos d’événements via QR code.

## Objectif

Créer une alternative originale, légalement distincte, à une application de collecte de photos d’événement.

Le positionnement du prototype :

> L’album privé que vos invités remplissent simplement en scannant un QR code.

## Lancer le projet

Ouvrir simplement le fichier `index.html` dans un navigateur.

Aucun serveur, aucune dépendance et aucune installation ne sont nécessaires.

## Fichiers

- `index.html` : structure de la landing page et de la démonstration.
- `style.css` : design responsive, mobile-first, mode sombre.
- `script.js` : interactions de démonstration.
- `PROMPT_CLAUDE_CODE.md` : prompt de démarrage pour Claude Code.
- `DOSSIER_REFERENCE.md` : dossier fonctionnel complet.
- `assets/` : dossier prévu pour les icônes et images futures.

## Fonctionnalités simulées

- Création d’un album.
- Génération de code album.
- Prévisualisation du nom de l’événement.
- QR code fictif.
- Copie du lien.
- Galerie dynamique.
- Ajout d’une photo fictive.
- Filtres de galerie.
- FAQ accordéon.
- Toasts de confirmation.
- Mode sombre.

## Note légale

Ce prototype est une version originale et indépendante.  
Il ne reprend pas l’identité, les textes, le design, le code, les logos, les captures ou les données d’un service existant.
